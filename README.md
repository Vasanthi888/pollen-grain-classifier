# Pollen Grain Profiling and Classification System

## Overview

This project is a web-based pollen grain classification system that uses a Convolutional Neural Network (CNN) to identify pollen grain types from uploaded microscope images.

The application allows users to upload an image through a Flask web interface and receive an automated prediction generated by a trained deep learning model.

## Features

* Upload pollen grain images through a web interface
* Deep learning-based image classification
* CNN model built using TensorFlow/Keras
* Flask-powered web application
* Automatic image preprocessing and prediction
* Label decoding using a saved Label Encoder

## Technologies Used

* Python
* TensorFlow / Keras
* Flask
* OpenCV
* NumPy
* Scikit-learn
* HTML

## Dataset

* Pollen grain image dataset obtained from Kaggle
* Images categorized into multiple pollen classes
* Dataset used for CNN model training and evaluation

## Project Workflow

1. Collect and preprocess pollen grain images
2. Train a Convolutional Neural Network (CNN)
3. Save the trained model (`model.h5`)
4. Save label mappings using LabelEncoder
5. Build Flask web application
6. Upload image through browser
7. Preprocess image using OpenCV
8. Generate prediction using trained CNN model
9. Display predicted pollen grain class

## Model Architecture

The project uses a Convolutional Neural Network (CNN) trained on pollen grain images.

The model learns visual features such as:

* Shape
* Texture
* Patterns
* Structural characteristics

to classify pollen grain categories.
